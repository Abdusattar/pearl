## Что осталось

1. Бот, шаг 2: текст о деньгах (снятие, передача, оплата поставщику) → черновик → формы Кассы/Оплаты.
2. Бот, шаг 3: скрин банка (остаток, платежи со счёта).
3. Бот, шаг 4: голос бота в группе («Принял», «Внесено», «уже присылали»).
4. Счёт: деньги Optima «в пути» — после проверки гипотезы «зачисление на следующий рабочий день».
5. «Старый вход»: оставить только владельцу (группы/классы, отчёты, посещаемость, меню там) — ждёт «да».
6. Тариф школы — владелец заводит в Настройках (одна цена на объект; по классам — доработка).
7. Optima: поля fio/organization/group для всех лицевых счетов — ждёт «да».
