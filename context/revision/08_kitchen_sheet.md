# 08. Экран «Лист кухни» — план кода нового входа

> 16.09.2026. Основание: макет версии 7, блок 3б (принят владельцем 15.09),
> реальный лист поваров за 10.09 (`media/столовая.jpeg`), решения: один лист
> на день без деления по приёмам пищи; повара в системе не ведут; Махабат
> вносит пачками раз в несколько дней. Статус: план на утверждение.

## Что показал реальный лист

17 строк, рукописных: «Картошка 3.200 кг», «Морковка 500г + 3,500»,
«Молоко 3 л», «Сахар 500г + 200», «Сливочный масло 200г», «Растительное
масло 300г − 810г», «Соль 500 гр», «специи: ч. перец, кр. перец 100 гр»,
«Укроп, кинза 2 шт», «сухофрукты» без числа, «рис 1,300», «Фарш 1,100 кг».
Три вещи, которые форма обязана уметь: **граммы и килограммы вперемешку**
(ошибки 10–11.09: 200 г → 200 кг, 4 кг → 4000), **несколько взятий за день
через плюс**, **мелочь без остатка** (зелень, специи).

## Что строим

`GET/POST /new/kitchen?date=` — один лист на день на площадке.

| Часть | В первом шаге |
|---|---|
| Шапка: день (по умолчанию первый невнесённый), «другой день», едоков одним числом | да |
| Строка: товар из каталога, «Взяли», «На складе» рядом | да |
| Единица из карточки; для кг можно ввести в г, для л в мл — переключатель у поля, сервер переводит | да (лягушка) |
| Поле количества принимает сумму: «0,5 + 3,5» | да |
| «Как вчера»: строки последнего внесённого листа, числа править | да |
| Мелочь (уровень категории minor): строка помечена «мелочь, не на складе», остаток не показывается | да |
| Взяли больше остатка: списывается что есть, остальное ложится «расхождением» на лист и в сигнал | да (по макету 3б) |
| Лист уже внесён: открывается на правку, «Внести» заменяет строки дня | да |
| После «Внести» предлагается следующий невнесённый рабочий день | да |
| Кнопка «Внести лист кухни» сверху и снизу | да |
| Фото листа приложить | да, файлом к листу |
| Фото → строки распознаванием | нет, единый конвейер после (решение 16.09) |

## Данные

**Новая таблица `kitchen_sheets`** — лист дня: площадка, дата (уникально на
площадку), едоков, фото (путь), заметка, расхождения (JSON: товар, взяли,
было), кто и когда, `deleted_at`. Нужна, чтобы «день внесён / не внесён»
было фактом, а не догадкой по наличию списаний (пересчёт и слияние тоже
пишут списания).

**Колонка `write_offs.sheet_id`.** Строки листа — обычные `WriteOff` с
`reason='лист кухни'`, `meal_type` NULL, `children_count` = едоков листа.
Старый склад видит их как раньше. Мелочь тоже пишется списанием (данные
для будущих норм); новый экран Склада остаток мелочи не показывает.

## Правила

- Единица не вводится. Переключатель только между единицей карточки и её
  дробной (кг ↔ г, л ↔ мл); хранится в единице карточки.
- «Взяли» = число или сумма чисел через «+». Пусто — строка пропускается.
- Остаток считается по площадке (org площадки), как везде в новом входе.
- Больше остатка: списание на остаток, разница в `shortfalls` листа с
  текстом «на складе было 1,5, взяли 3». Показывается на листе после
  записи и пойдёт сигналом в Обзор/«Ждёт вас».
- Правка листа: старые строки дня помечаются `deleted_at`, пишутся новые;
  AuditLog хранит старый состав.
- Невнесённые дни: рабочие дни площадки от последнего внесённого листа до
  сегодня. **Рабочие дни — понедельник–пятница** (вопрос владельцу, потом
  в Настройки).
- Товары в подсказке: сначала основные с остатком > 0, потом остальные
  активные карточки; новую карточку здесь не заводят (только в «Купили»).

## Где живёт код

- `app/routers/new_kitchen.py` (тот же префикс `/new`), шаблон
  `new/kitchen.html` на `new/base.html`.
- `app/services/kitchen.py`: `missing_days`, `last_sheet_rows`,
  `parse_qty` (сумма, дробная единица), `save_sheet` (замена строк,
  расхождения), `stock_map` по площадке (обёртка над
  `warehouse._get_balance_map`, вынести в сервис).
- Миграция: таблица + колонка.

## Проверки

- Тесты: «200 г» масла → 0,2 кг; «0,5 + 3,5» → 4; чужая единица —
  ошибка; «как вчера» подставляет; мелочь пишется без проверки остатка;
  сверх остатка → списано 1,5, расхождение 1,5; повторное «Внести» за тот
  же день заменяет строки, старые с `deleted_at`; следующий невнесённый
  день считается по рабочим дням; едоков попадает в каждую строку.
- Живой прогон на копии прода: лист за 10.09 с фото руками, 17 строк.
